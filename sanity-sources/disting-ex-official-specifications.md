# Expert Sleepers Disting EX — official specifications

Product: Disting EX

Manufacturer: Expert Sleepers

Official source: https://www.expert-sleepers.co.uk/distingEX.html

Source section: Specifications

## Physical and power specifications

- Panel width: 8HP
- Module depth: 50mm
- Current draw on the +12V rail: 229mA
- Current draw on the -12V rail: 50mA
- Input and output voltage range: ±10V

## Variant identity

Disting EX and Disting NT are separate Eurorack module models. Values in this document apply only to Disting EX and must not be used as specifications for Disting NT.

## Retrieval instruction

Use this source only when the selected module is Disting EX. Do not transfer measurements or electrical requirements between Disting EX, Disting NT, or earlier Disting models.
